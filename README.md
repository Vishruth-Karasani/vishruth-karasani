# Hi, I'm Vishruth

I start by listening to users, mapping the mess, and turning it into something buildable!

I work across product management, business analysis and analytics. My work starts with listening: more than 140 structured interviews across user research, field studies and practitioner research. From there I write it down so teams can build it, as requirements, user stories and process maps, and then check whether the data says it worked.

Running through all of it is AI governance: who is accountable, what could go wrong, and how a user can challenge an outcome. I treat those as design questions, not compliance paperwork.
